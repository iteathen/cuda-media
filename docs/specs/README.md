# CUDA-MEDIA specifications

**Architecture/ownership authority is accepted; no production media capability specification is accepted yet.**

- [`SPEC-0001-native-boundary-and-js-only-implementation.md`](SPEC-0001-native-boundary-and-js-only-implementation.md) — accepted cross-cutting rule that CUDA-MEDIA remains JavaScript/TypeScript, CUDA-JS owns native media/graphics/memory/provider integration, and image/frame/video/codec semantics remain here. This specification does not select a provider or authorize a media profile.

The [activation roadmap](https://github.com/iteathen/cuda-media/issues/3) organizes assessment. Production implementation must first have a bounded, consumer-backed semantic contract accepted under the [development instructions](../../AGENTS.md).

Start with the [project charter](../PROJECT_CHARTER.md) and [architecture decision](../decisions/README.md) to understand the intended scope.
